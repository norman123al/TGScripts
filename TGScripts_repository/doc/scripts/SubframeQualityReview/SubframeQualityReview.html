1 Description

[hide]

Subframe Quality Review helps you decide which original light frames to exclude before rerunning WeightedBatchPreprocessing (WBPP). It measures the calibrated and registered images from a completed WBPP run, identifies potentially poor subframes within each comparable group, and lets you inspect them against the best scoring subframe or the linear filter master.

The default shortlist contains the worst 10% of measured subframes in each group. REVIEW is a suggestion to inspect an image. Only your explicit rejection decisions are included in a move operation. The corresponding original, uncalibrated files are moved to your chosen folder after you confirm the move plan.

The script supports monochrome images and registered, debayered OSC images from one telescope setup. Optional corner measurements help reveal focus or star-shape problems near the edges. Quality plots can show the acquisition sequence and autofocus start times from the Autorun logs in a selected folder.

2 Start and complete a review

[hide]

With TGScripts installed through the standard PixInsight script installation, choose Script > TG Scripts > Subframe Quality Review. The script requires PixInsight 1.9.5 or later. Use the documentation button at the lower right to reopen this guide.

  1. Complete a WBPP run. Keep its calibrated and registered lights and its linear, per-filter integrations. Use masters with the same image dimensions as the registered lights; do not crop or drizzle the masters for this review.
  2. Select the WBPP output directory, the original-light root, and a destination for rejected originals. Optionally select a log folder containing the acquisition and guiding logs.
  3. Click Scan files. Check the Filter / group selector and the Original association column. Each original that can be moved must have a unique, verified association.
  4. Leave Measure corners disabled for a faster first review, or enable it to evaluate the center and four corners. Enabling it starts measurement automatically when regional data is missing and input folders have been selected. Set Review worst (%) and the quality weights as needed.
  5. Click the magnifier button at the bottom if measurements are still needed. The measurement run covers all discovered groups and their matched masters.
  6. Review the measurements and quality plots. Select a subframe and open the Blink frame / reference tab, or double-click its row. Inspect the images before deciding which originals to reject.
  7. Use the Reject column, the Space key on a selected row, or Reject original in the blink tab to mark unwanted originals. REVIEW flags alone do not mark a file for moving.
  8. Click the green checkmark to review the move plan. Confirm it to move the marked original lights to the rejection destination.
  9. Rerun WBPP with the remaining originals. Refresh its light-frame input list so it no longer includes the moved files. Keep the rejection destination out of the new input selection.

Measurements and pending rejection decisions remain in memory while the dialog is open. Closing the dialog discards them. The New Instance button saves folder and evaluation settings in a process icon; it does not save a measured review session.

Click the WBPP run and original lights bar to collapse or expand the folder and log controls. It opens expanded by default. The window keeps its size, and the active tab uses the space released by a collapsed section. Collapsing it retains the selected paths, settings, measurements, and rejection choices. Saved process instances remember its expanded or collapsed state.

5 What is measured

[hide]

The script calls PixInsight's SubframeSelector process to measure the registered lights and the matching masters. It uses a shared valid field inside the registered images, excluding registration borders as far as the sampled border checks can determine. FWHM is reported in pixels.

Measurements are performed on temporary, floating-point image crops. This allows signal and noise information to be evaluated for the measured region without reusing inherited WBPP noise metadata. Source images are opened for reading; their pixels and metadata are not changed.

Field measurements for all groups and masters are submitted together to SubframeSelector. Optional center and corner crops are submitted in a second batch. SubframeSelector manages processing concurrency using its normal defaults, as in WBPP; the script does not impose a fixed number of frames per batch.

With corner measurements enabled, each of the four corners is evaluated for FWHM, FWHM relative to the center, and eccentricity. These measurements use the registered image orientation. After rotation or a meridian flip, a displayed corner does not necessarily correspond to the same physical camera corner.

Measurements describe the processed, registered images. Their PSF signal weights need not equal the values originally recorded by WBPP at an earlier processing stage. Very sparse regions, unusual star profiles, or registration artifacts merit visual inspection even when a numerical score is available.

6 Sky background

[hide]

With Measure corners enabled, Sky background is the minimum of the arithmetic means of the five previews: Center, Top left, Top right, Bottom left, and Bottom right. With Measure corners disabled, it is the arithmetic mean of the whole registered image, including any registration borders.

Values are reported in image units. For RGB images, the mean includes all three color channels equally. Stars and extended objects remain part of the means; this indicator is an estimate, not a measurement of empty sky alone. Compare images with the same brightness scale and processing. Background subtraction or normalization can change its interpretation.

Lower values are treated as better quality. Sky background has a default manual weight of 20; set it to zero to exclude it from Score. It also participates in Below-mean Quality and, when enabled, the selection of strongly correlated KPIs using the current background measurement. R1 uses the whole-image mean; R2 uses the preview minimum. Switching Measure corners updates the displayed value, Score, and R3 selection.

The Review table reports Sky background with six decimal places. Hover over the value to see its meaning and the five preview means when available. Choose Sky background on the Quality indicators or Correlation plot tab, or in Sort by. Missing background measurements are shown as unavailable and do not count as good quality. All five preview means are required to establish their minimum; star-detection success is not required for a pixel mean.

7 Score and Below-mean Quality

[hide]

Higher Score means better relative quality. Scores range from 0 to 1 and are displayed with three decimal places. The default Score sort puts the lowest, worst scores first. The score combines penalties for weak signal, few detected stars, large or elongated stars, high sky background, optional corner problems, guiding errors when logs are available, and the breadth of below-mean quality across indicators.

For each image-based field indicator, the reference is the median of the group's supported subframe measurements. Its scale is the larger of 1.4826 times the median absolute deviation, 2% of the absolute median, and a tiny numerical floor. The master is excluded from these reference statistics.

For an indicator where higher is worse, the penalty is (value minus median) divided by the scale. For an indicator where lower is worse, it is (median minus value) divided by the scale. Negative penalties become zero, and penalties above 10 are capped at 10. A good result in one indicator therefore does not cancel a poor result in another.

Corner quality is the worst penalty for star size, corner-to-center size ratio, or elongation across the four corners. Lower is better.

Below-mean Quality uses arithmetic means, not medians. It is the percentage of assessed, enabled underlying indicators on the poor-quality side of their mean. Low PSF signal weight and low star count count as worse; high FWHM, high eccentricity, high Corner quality penalties, high sky background, and high guiding error count as worse. Equality with the mean is not worse. Score and Below-mean Quality itself are excluded from this comparison.

For example, a subframe worse than the mean in three of four assessed indicators has Below-mean Quality of 75%. Its score penalty uses the fraction 0.75 directly. With the default weight of 20, it adds 0.75 times 20 to the weighted numerator. Setting the Below-mean Quality weight to zero removes this score contribution while keeping the percentage visible.

Score = 1 − sum(weight × penalty) / (10 × sum of weights). Only available components enter the sums. A Score of 1.000 means no measured penalty; 0.000 means the weighted mean penalty reaches its limit of 10. Score describes relative quality within its group, not a probability or an absolute image-quality rating. Rankings use full precision, so values that display identically can have different ranks.

The arithmetic means used for Below-mean Quality include supported subframes in the group, including manually rejected subframes, and exclude the master. Disabling an underlying component by giving it zero weight also excludes it from the Below-mean Quality comparison. Corner quality counts as one indicator when corner scoring is enabled and weighted.

Unavailable indicators are not treated as good measurements. An incomplete Below-mean Quality percentage is marked with an asterisk; its tooltip gives the assessed and enabled counts. A partial Score may still be displayed, but missing required data triggers REVIEW, and R1 and R2 are withheld when their required measurements are unavailable. A partial R3 remains available when the field measurement is valid; inspect its missing-data flags.

Enable Use strongly correlated KPIs (|r| >= 0.7) to select the scoring indicators automatically for each group. The selection uses absolute Pearson correlation with PSF signal weight, accepting both positive and negative relationships. It requires at least three paired subframes with varying measurements. The master is excluded; manually rejected subframes remain included. Strong correlation describes association, not the cause of poor quality, and can be unstable in small groups.

PSF signal weight remains the anchor. Each other selected component has weight 1; excluded components have weight 0. Manual weight values are retained, including any zeros, and restored when the option is disabled. Corner quality participates only when Measure corners is enabled; guiding also requires logs and a guiding mode other than Ignore. The selected guiding mode still controls missing-data handling when guiding is included.

With Measure corners enabled, the FWHM and eccentricity of each of the four corners are also tested separately against PSF signal weight. Each of these eight indicators is included with weight 1 when its absolute correlation reaches 0.7 with at least three valid paired subframes. The Corner quality composite remains a separate candidate. A corner FWHM can qualify even if eccentricity or another corner is unavailable. Center FWHM contributes through the composite's corner-to-center ratios; it is not a separate scoring candidate.

Each selected corner indicator contributes its own penalty and enters the Below-mean Quality comparison. Larger FWHM and eccentricity are worse, regardless of the correlation's sign. Several qualifying corner indicators therefore give corner performance more combined influence. Disabling correlation scoring restores the manual weights and the single Corner quality contribution.

Below-mean Quality is first recalculated from the selected underlying indicators, then included only if its own correlation passes the threshold. Score itself is never a selection candidate. If no other indicator qualifies, Score uses PSF signal weight alone. Included KPIs are listed in the bottom message area on every tab and in the Review summary for the current group. Hover over either report or R3 for each correlation, sample count, and exclusion reason. Changing this option reuses existing measurements.

If Measure corners is enabled afterwards, missing regions are measured automatically and the selection is recalculated for every group. Corner quality and the eight individual corner indicators are included only when each meets the strong-correlation threshold. Disabling corners removes all of these components and recalculates the selection again.

The master receives comparable measurements and a score against the subframe baselines. It does not influence the baselines or consume a place in the REVIEW quota. Guiding measurements apply only to individual exposures, so the master has no guiding contribution.

All eight manual Score components have columns: PSF weight, FWHM, Stars, Field eccentricity, Corner quality, Below-mean Quality, Guiding quality, and Sky background. In correlation mode, columns for qualifying individual corner FWHM and eccentricity indicators appear at the right of the table; scroll horizontally to view them. Main issue identifies a scoring contribution, not a diagnosis. For example, elongated stars may be associated with guiding, wind, or optical effects; inspect the image to decide whether to reject it. Hover over the score, issue, or quality columns for contribution details and missing-data information.

R1, R2 and R3 include the master in their comparison ranking. Their values remain group ranks when the table is filtered; they are not renumbered as visible row positions. Equal scores are resolved consistently by filename.

Use Sort by in the Sort and filter area. Score, field-width, corner-quality, sky-background, and Below-mean Quality sorts show the poorest values first; PSF signal weight and star count show the smallest values first. R1, R2 and R3 show rank 1 first. The button beside the selector shows Ascending or Descending. Click it to toggle the direction. Choosing another criterion restores that criterion's default direction. The selected criterion and direction are saved in process instances. Below-mean Quality keeps complete comparisons first, with Score resolving percentage ties in the chosen direction; incomplete comparisons follow in both directions.

Acquisition time starts with the earliest full date and time. Toggle to Descending for latest first. In both directions, dated subframes come first, undated subframes follow, and the master is last. Filename sequence numbers do not participate in this ordering. Sorting preserves the selected image and manual rejection choices. The quality plots retain their own order.

Choose Guide minimum, Guide maximum, or Guide average to sort by the corresponding guiding column. These start with the largest error first; use the direction button to put the smallest error first. Values are sorted numerically in arcseconds, including partial measurements marked with an asterisk. Unavailable values follow measured values in both directions, and the master is last. The choice and direction are saved in process instances and also determine the sequence for Rotate subframes (Review order).

Enable REVIEW candidates only to show just flagged subframes. This filter also hides the master. It changes table visibility without marking files for rejection or limiting the quality plots to those rows.

Hover over a REVIEW marker to see why the image was selected. For the Review worst percentage, the tooltip gives its group position, the rounded-up shortlist size, Score, and largest score penalties. It also lists any missing or insufficient measurements and guiding-data issues that require inspection. Both reasons appear when both apply. The explanation follows the current scoring settings and stays consistent when the table is sorted or filtered. REVIEW leaves the rejection decision to you.

When corner measurements are enabled, the REVIEW tooltip also explains unavailable preview measurements individually. It reports the detected-star count and required minimum, a missing or invalid FWHM or eccentricity result, or the recorded processing error. A preview with no result is described as not measured. When the measurement process supplies no detailed cause, the tooltip says so. These details also remain visible for missing regional indicators excluded by correlation scoring; their presence alone does not add a REVIEW flag.

Click a row to select it. Clicking the same selected row again deselects it. Keyboard navigation selects rows; Space toggles rejection of the selected eligible original. Double-click a row outside the Reject column to open it for blinking. Selection, REVIEW status, and rejection are separate states.

9 Blink frame and reference

[hide]

Blink mode defaults to Best scoring subframe. This chooses the highest-scoring eligible measured subframe in the group that has not been rejected or moved. Filter master uses the automatically matched linear integration. The master association is retained for each filter group.

The region selector offers the field, center, and four corners. The preview can display these regions even when optional numerical corner measurements have not been run. Display stretch and brightness alignment affect the preview only. A common reference-derived stretch helps comparison, and brightness alignment reduces global background and contrast differences.

The coordinate strip shows Zoom, X, Y, and Value under the mouse pointer. Value is the displayed preview pixel normalized to 0–1, including any display stretch and brightness alignment, with separate R/G/B values for color images. It has 8-bit display precision. Coordinates are relative to the selected region. The readout follows the displayed image during blinking and updates after zooming, panning, and changing regions; it clears outside the image.

Choose Rotate subframes (Review order) to cycle through the subframes currently visible in Review and measurements. Rotation follows its sorting criterion, direction, and REVIEW candidates only filter. The master is always excluded. It starts from the selected subframe, or the first visible subframe if none is selected, and wraps from the last to the first. The filename and position in the sequence identify the displayed subframe. Keep and Reject apply to that subframe. At least two visible subframes are needed for automatic rotation.

In rotation mode, the first displayed subframe supplies the common preview stretch and brightness alignment. Press Play to start, Stop to pause, or Step to pause and advance one subframe. Previous and Next follow the same sequence and skip the master. Changing tabs pauses rotation.

With Rotate regions set to Off and Filter master or Best scoring subframe selected, press the play symbol to start alternating the selected image and reference. While playing, the button shows a stop symbol; press it to pause. Step pauses automatic blinking and switches to the other image.

10 Quality indicators and acquisition order

[hide]

The Quality indicators tab shows one selected indicator at a time, with Score selected initially. The plots follow WBPP's per-frame style: each image occupies one bar position. They do not aggregate images into frequency bins.

The note beside the selected indicator shows whether higher or lower values are preferable and whether it is included in Score under the current settings. A zero weight, disabled corner scoring, or excluded guiding is identified. In correlation mode, each corner FWHM and eccentricity reports its own inclusion or exclusion. In manual mode these measurements contribute through Corner quality; Center FWHM is used in corner/center ratios. Guide minimum, average, and maximum contribute through combined guiding quality when coverage is usable. Score itself is the combined result. Plotted measurements remain available even when their scoring contribution is disabled.

Selecting Corner quality displays its definition above the plot: the worst penalty for star size, corner-to-center size ratio, or elongation across the four corners. Lower is better. Missing measurements are flagged separately.

Choose Order by: KPI value for ascending values, or Acquisition time for the acquisition sequence. The plot order is independent of the review table. In chronological plots the master is first, dated subframes run from earliest to latest, and undated subframes follow. Bar spacing is uniform; the horizontal axis is an image sequence, not a proportional elapsed-time axis.

Field eccentricity and each corner eccentricity plot use a fixed zero-to-one axis with green, amber, and red background bands. Good eccentricity is at or below 0.42; Medium is above 0.42 and at or below 0.60; Bad is above 0.60. The legend and dotted lines mark these boundaries in both KPI-value and acquisition-time order. Hover over a bar to see its category. Eccentricity is dimensionless: zero is round and values approaching one indicate increasingly elongated stars. These ranges are practical inspection guidelines. Score continues to compare eccentricity within the group; the bands do not change scoring or automatically reject an image.

For Guide minimum, Guide average, and Guide maximum, green, amber, and red background bands mark Good, Medium, and Bad guiding. The legend gives the boundaries in arcseconds, and dotted lines separate the bands. The vertical range includes zero and all three categories, as well as the measured values. These bands appear in both KPI-value and acquisition-time order when the imaging scale is available. The bar colors still identify selection, review, and rejection status. No category boundaries are drawn when the imaging scale is unavailable.

The Guiding quality plot shows the combined indicator without category bands. Its definition appears above the plot: G = (minimum + 2 times average + maximum) / 4, in arcseconds. The average contributes 50 percent, and the minimum and maximum each contribute 25 percent. Lower values are better. The displayed minimum, average, and maximum categories help inspect individual guiding measurements; the combined value G determines the guiding penalty used in Score.

The green plot mean excludes rejected subframes and can change as you make decisions. The scoring baselines and the arithmetic means behind Below-mean Quality use all supported subframes in the group, including rejects. These intentionally serve different purposes.

Acquisition timestamps come first from the verified original's DATE-OBS or DATEOBS metadata, then from the registered image. Separate TIME-OBS or TIMEOBS fields are supported when the date field contains only a date. Explicit timezone offsets are converted to UTC; timestamps without an offset are interpreted as UTC. The table shows the same UTC timestamp used by the plots.

Acquisition filenames may show a local clock or an end time while the header records a UTC exposure start. The displayed Acquisition time (UTC) is the authoritative value used by this script. The filename counter suffix is ignored.

11 Correlation plot

[hide]

Open the Correlation plot tab and choose any two quality indicators with X axis and Y axis. The plot and Pearson correlation coefficient update immediately. Swap axes exchanges the selections without changing the correlation. The initial pair is Field FWHM on X and PSF signal weight on Y.

Regional KPIs appear in both selectors only when corresponding subframe measurements are available in the current group. Enable Measure corners to measure missing regions and add these choices. Stored regional results remain selectable when corner scoring is turned off. If a selected KPI becomes unavailable after changing groups or clearing measurements, that axis returns to its initial selection; the other axis is retained when available.

Each point represents one subframe with both measurements available. 12 Log folder, timing, and autofocus markers

[hide]

Select Log folder in the directory section. All Autorun_log and PHD2_GuideLog files are read directly from this folder, regardless of letter case. Include continuation logs if acquisition was restarted. Files marked _CHN are ignored because they are translated copies. Subfolders and unrelated logs are not processed. Select the folder again to refresh its contents.

Autofocus starts from all matching logs are combined in chronological order. Overlapping logs produce one marker per start. An unreadable log is listed in Autofocus times; readable logs are still used. The report lists the source filenames for every start. If duplicate logs report different final positions for the same start, the position is marked as conflicting and the plot shows AF without a position.

The script reads lines such as 2026/09/05 23:08:11 [AutoFocus|Begin] followed by the autofocus trigger description. It pairs each start with the final successful focus position from that run. For example, the later line 2026/09/05 23:11:19 Auto focus succeeded, the focused position is 692 produces the label AF 692 at the 23:08:11 start. Intermediate EAF positions are ignored. If no successful position is reported, the label remains AF. Repeated entries with the same start are deduplicated, and invalid start timestamps are reported as skipped.

Both log types use local time. Infer from image timestamps compares the local timestamp in each subframe filename with its UTC exposure-start metadata. It accounts for filenames that record exposure completion. The inferred offset appears below the log controls and applies to both autofocus markers and guiding samples. The filename timestamp must have the form YYYYMMDD-HHMMSS or YYYYMMDD_HHMMSS.

If the offset cannot be determined unambiguously, choose Custom UTC offset and enter local time minus UTC in hours, such as +2 for UTC+02:00 or +5.5 for UTC+05:30. The current computer's timezone is never assumed. At a daylight-saving transition, ambiguous times remain unresolved rather than being assigned to an exposure by guesswork.

The console reports all extracted autofocus starts as written in the log and converted to UTC, together with each final focus position or not reported. Click Autofocus times to view and copy the same list. Changing the folder or timestamp convention updates the report and markers without remeasuring the images. Clearing the folder removes the markers and retains image measurements.

Autofocus markers appear only when image-quality plots use Acquisition time order. The guiding minimum, maximum, average, and quality plots omit autofocus markers and their legend. Only starts within the earliest-to-latest known subframe timestamps of the current group are shown. A start between two subframes is placed between their bar positions. Hover over the AF tag to read its log time, UTC time, final focus position, and trigger description. Markers use the start time even though the final position is reported later; no end time or duration is displayed.

All extracted starts remain in the report, including starts outside the current group's time range. If markers appear at unexpected positions, compare the UTC acquisition column with the converted times in Autofocus times and check the log's timezone setting.

13 Guiding measurements and quality

[hide]

The script matches PHD2 samples to each subframe's UTC exposure start and duration. Guide min, Guide max, and Guide avg report the combined RA/Dec displacement in arcseconds. The guider's recorded pixel scale converts its measurements to arcseconds; the imaging camera's pixel scale sets the quality thresholds.

Let p be the image pixel scale in arcseconds per pixel. The guiding quality value is:

G = (minimum + 2 * average + maximum) / 4

The average contributes 50 percent, and the minimum and maximum each contribute 25 percent. This balances typical performance with the observed extremes. For unequal X/Y image scales, the smaller available scale is used. The UI displays the Good, Medium, and Bad boundaries in arcseconds for your setup. For example, an image scale of approximately 0.507 arcseconds per pixel gives a Good limit of approximately 0.507 arcseconds and a Medium limit of approximately 0.887 arcseconds; larger errors are Bad.

Table 8

Category

Guiding quality value

Good guiding

G is equal to or below p.

Medium guiding

G is above p and equal to or below 1.75 times p.

Bad guiding

G is above 1.75 times p.

Guiding adds a penalty of (G / p minus 1) divided by 0.75, bounded between zero and 10. Good guiding therefore has zero penalty; the upper medium boundary has a penalty of one. Weight in the Guiding group sets its relative Score weight, with a default of 25. Set it to zero to exclude guiding from Score while retaining the measurements. The quality plots show the three guiding statistics and the combined guiding quality value G, all in arcseconds.

14 Move rejected originals and rerun WBPP

[hide]

The green checkmark opens a move-plan review. It includes only manually rejected subframes with verified original files. Review the listed filenames and destination before confirming.

The script checks the complete plan before moving files. It verifies the original associations and file fingerprints, preserves each original's relative directory structure, and refuses to overwrite destination files. The calibrated images, registered images, masters, and calibration originals are not moved.

A move journal named SQR-moves followed by a timestamp and a .json extension is saved in the rejection destination. Keep it with the moved files so that you can undo the move later.

To restore a moved original, select its row and click the Undo arrow beside the green checkmark. The Undo moved originals dialog preselects that file and shows its original path. Select additional files if needed, then click Restore selected. Restored files return to their original folders and their rejection marks are cleared in the current review.

Undo also works after rescanning or reopening the script. Click the Undo arrow, choose the original SQR-moves journal from the rejection folder, and select the files to restore. Select available checks all eligible files; Clear selection lets you start with none. You do not need to measure the images again to restore them.

Files that have changed, are missing, or have an occupied original path cannot be restored. Existing files are never overwritten. Already restored files are identified in the list. If restoration stops partway through, reopen the same move journal to restore the remaining eligible files. Each restoration also saves an SQR-undo journal in the rejection folder.

After moving, rerun WBPP from the remaining originals. Refresh its inputs and exclude the rejection directory. Use an output directory appropriate for the new run so that you can distinguish the new integration from the reviewed run.
