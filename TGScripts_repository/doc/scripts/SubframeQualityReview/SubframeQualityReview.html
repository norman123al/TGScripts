1 Description

[hide]

Subframe Quality Review helps you decide which original light frames to exclude before rerunning WeightedBatchPreprocessing (WBPP). It measures the calibrated and registered images from a completed WBPP run, identifies potentially poor subframes within each comparable group, and lets you inspect them against the best scoring subframe or the linear filter master.

The default shortlist contains the worst 10% of measured subframes in each group. REVIEW is a suggestion to inspect an image. Only your explicit rejection decisions are included in a move operation. The corresponding original, uncalibrated files are moved to your chosen folder after you confirm the move plan.

The script supports monochrome images and registered, debayered OSC images from one telescope setup. Optional corner measurements help reveal focus or star-shape problems near the edges. Quality plots can show the acquisition sequence and autofocus start times from the Autorun logs in a selected folder.

2 Start and complete a review

[hide]

With TGScripts installed through the standard PixInsight script installation, choose Script > TG Scripts > Subframe Quality Review. The script requires PixInsight 1.9.5 or later. Use the documentation button at the lower right to reopen this guide.

  1. Complete a WBPP run. Keep its calibrated and registered lights and its linear, per-filter integrations. Use masters with the same image dimensions as the registered lights; do not crop or drizzle the masters for this review.
  2. Enter the telescope aperture for FWHM grading, then select the WBPP output directory, the original-light root, and a destination for rejected originals. Optionally select a log folder containing the acquisition and guiding logs.
  3. Click Scan files. Check the Filter / group selector and the Original association column. Each original that can be moved must have a unique, verified association.
  4. Set Review worst (%) and the quality weights as needed.
  5. Click the magnifier button at the bottom for a field measurement. To include the center and four corners, click the adjacent Measure corners grid button. It reuses existing field results; if these are missing, it measures the field first. Both actions cover all discovered groups and their matched masters.
  6. Review the measurements and quality plots. Select a subframe and open the Blink frame / reference tab, or double-click its row. The image preview loads when needed. Repeating a measurement reuses unchanged results and an unchanged loaded preview. Inspect the images before deciding which originals to reject.
  7. Use the Reject column, the Space key on a selected row, or Reject original in the blink tab to mark unwanted originals. REVIEW flags alone do not mark a file for moving.
  8. Click the green checkmark to review the move plan. Confirm it to move the marked original lights to the rejection destination.
  9. Rerun WBPP with the remaining originals. Refresh its light-frame input list so it no longer includes the moved files. Keep the rejection destination out of the new input selection.

Corner measurements automatically adapt parallel processing to the available CPU and memory. No additional settings are required.

Measurements and pending rejection decisions remain in memory while the dialog is open. Closing the dialog discards them. The New Instance button saves folder and evaluation settings in a process icon; it does not save a measured review session. Loading saved settings starts with no corner measurements.

3 Input files and observing conditions

[hide]

Click the Input files and observing conditions bar to collapse or expand the telescope, folder, and log controls. It opens expanded by default. The window keeps its size, and the active tab uses the space released by a collapsed section. Collapsing it retains the selected paths, settings, measurements, and rejection choices. Saved process instances remember its expanded or collapsed state.

Telescope aperture is at the bottom of this section, aligned with the folder controls. Enter the imaging telescope's aperture diameter in whole millimeters. It is required for FWHM grading and is initially unset; it is not needed to measure or review the images.

Zenith seeing is beside Aperture. Enter an optional seeing estimate in arcseconds at the zenith and a reference wavelength of 550 nm. A positive value enables grading relative to the expected FWHM for those conditions. Leave it at zero to use the fixed Good and Medium seeing limits. A forecast is an estimate, not a measurement of the actual conditions; check its reference conditions before entering it. If it already includes the target altitude correction, convert it to zenith seeing first.

Session SQM and SQM time (local) are beside Aperture and Zenith seeing. Enter the reading in mag/arcsec². Loading the log folder presets the date and local time from the earliest light-frame sequence in its Autorun logs. Flat frames, focusing and plate-solving exposures, and Chinese translations are ignored. Adjust the preset to the actual SQM reading time. A time you enter manually is retained when the logs are reloaded or changed; an untouched automatic preset follows the selected log folder. This distinction is retained in saved settings. If the new folder has no recognized light-frame start, an automatic preset is cleared.

Click Choose beside SQM time to select the year, month, day, hour, minute and second, then Apply. Cancel retains the existing time. If the time is empty, the selector starts at the logged imaging start, then falls back to the selected exposure midpoint when its local time is known, or the computer clock if neither is available. You can also type or paste YYYY-MM-DD HH:MM or YYYY-MM-DD HH:MM:SS directly. The date avoids ambiguity when a session crosses midnight. Log presets keep their local wall time; the existing inferred or custom UTC offset converts the reading to image UTC timestamps. The reading automatically determines the approximate Bortle class.

Zero means that no SQM reading is supplied. In that case, select Sky background on the Quality indicators tab to choose a Bortle class from the compact selector to the left of Calibrate sky. Choose a class from 1 to 9, or — when unspecified. The starting selection is class 6. Your manual selection is retained while SQM determines the class automatically.

4 Quality evaluation controls

[hide]

Click the Quality evaluation bar to collapse or expand the section. It opens expanded by default. The window keeps its size when either section is toggled. Collapsing it retains all settings, measurements, scores, and rejection choices. Saved process instances remember the expanded or collapsed state.

The first column separates Measurements and review from Score selection. Measurements and review has Review worst and Minimum stars in the left column, with Edge guard and Corner size in the right column. Score selection contains the three checkboxes that determine the active Score. Its bold Current Score label identifies the selected R1, R2, R3, or R4 method. Score weights sets the manual weights in two columns. Guiding contains its scoring mode, weight, and thresholds. The active scoring mode is also reported in the bottom message area.

With the R3 and R4 options off, manual scoring uses R1 for field-only evaluation or R2 when corner measurements are included. The strongly correlated KPI option selects R3; the rank-of-ranks option selects R4. These two options are alternatives. The corner checkbox determines whether available corner measurements participate in the selected method.

5 What is measured

[hide]

The script calls PixInsight's SubframeSelector process to measure the registered lights and the matching masters. It uses a shared valid field inside the registered images, excluding registration borders as far as the sampled border checks can determine. FWHM is reported in pixels with one decimal place.

Measurements are performed on temporary, floating-point image crops. This allows signal and noise information to be evaluated for the measured region without reusing inherited WBPP noise metadata. Source images are opened for reading; their pixels and metadata are not changed.

Field measurements cover all groups and their matched masters. Optional center and corner measurements follow, with parallel processing adapted to your computer's available memory and PixInsight processing limits. Existing field measurements are reused when adding corners.

After you click the magnifier, the script checks the common usable field, measures missing field results and any enabled missing regions, and updates the scores. For sky calibration, an SQM reading uses the measured frame nearest its reading time. Without SQM, a selected Bortle class uses Gaia photometry on the best default-scoring frame. Gaia sky-coordinate repair, when needed, can make this last step take longer. The console shows progress. Repeating measurement in the same open review reuses unchanged results and sky calibration. Opening the Blink tab loads the image preview when needed.

With corner scoring enabled, each of the four corners is evaluated for FWHM, FWHM relative to the center, and eccentricity. These measurements use the registered image orientation. After rotation or a meridian flip, a displayed corner does not necessarily correspond to the same physical camera corner.

Measurements describe the processed, registered images. Their PSF signal weights need not equal the values originally recorded by WBPP at an earlier processing stage. Very sparse regions, unusual star profiles, or registration artifacts merit visual inspection even when a numerical score is available.

6 Sky background

[hide]

With Include corner measurements (R2) enabled, Sky background is the minimum of the arithmetic means of the five previews: Center, Top left, Top right, Bottom left, and Bottom right. With the option off, it is the arithmetic mean of the whole registered image, including any registration borders.

Values are reported in image units. For RGB images, the mean uses the green channel. Stars and extended objects remain part of the means; this indicator is an estimate, not a measurement of empty sky alone. Compare images with the same brightness scale and processing. Background subtraction or normalization can change its interpretation.

Lower values are treated as better quality. Sky background has a default manual weight of 20; set it to zero to exclude it from Score. It also participates in Below-mean Quality and the R3 selection of strongly correlated KPIs using the current background measurement. R1 uses the whole-image mean; R2 uses the preview minimum. Switching corner scoring updates the displayed value, Score, R3 selection, and R4.

The Review table reports Sky background with six decimal places. Hover over the value to see its meaning and the five preview means when available. Choose Sky background on the Quality indicators or Correlation plot tab, or in Sort by. Missing background measurements are shown as unavailable and do not count as good quality. All five preview means are required to establish their minimum; star-detection success is not required for a pixel mean.

7 Score and Below-mean Quality

[hide]

Higher Score means better relative quality. Scores range from 0 to 1 and are displayed with three decimal places. The default Score sort puts the lowest, worst scores first. The score combines penalties for weak signal, few detected stars, large or elongated stars, high sky background, optional corner problems, guiding errors when logs are available, and the breadth of below-mean quality across indicators.

For each image-based field indicator, the reference is the median of the group's supported subframe measurements. Its scale is the larger of 1.4826 times the median absolute deviation, 2% of the absolute median, and a tiny numerical floor. The master is excluded from these reference statistics.

For an indicator where higher is worse, the penalty is (value minus median) divided by the scale. For an indicator where lower is worse, it is (median minus value) divided by the scale. Negative penalties become zero, and penalties above 10 are capped at 10. A good result in one indicator therefore does not cancel a poor result in another.

Corner quality is the worst penalty for star size, corner-to-center size ratio, or elongation across the four corners. Lower is better.

Below-mean Quality uses arithmetic means, not medians. It is the percentage of assessed, enabled underlying indicators on the poor-quality side of their mean. Low PSF signal weight and low star count count as worse; high FWHM, high eccentricity, high Corner quality penalties, high sky background, and high guiding error count as worse. Equality with the mean is not worse. Score and Below-mean Quality itself are excluded from this comparison.

For example, a subframe worse than the mean in three of four assessed indicators has Below-mean Quality of 75%. Its score penalty uses the fraction 0.75 directly. With the default weight of 20, it adds 0.75 times 20 to the weighted numerator. Setting the Below-mean Quality weight to zero removes this score contribution while keeping the percentage visible.

Score = 1 − sum(weight × penalty) / (10 × sum of weights). Only available components enter the sums. A Score of 1.000 means no measured penalty; 0.000 means the weighted mean penalty reaches its limit of 10. Score describes relative quality within its group, not a probability or an absolute image-quality rating. Rankings use full precision, so values that display identically can have different ranks.

The arithmetic means used for Below-mean Quality include supported subframes in the group, including manually rejected subframes, and exclude the master. The saved manual weights determine which underlying indicators participate: a zero weight excludes an indicator from this comparison. Corner quality counts as one indicator when corner scoring is enabled and weighted. Selecting R3 or R4 changes the active Score without changing Below-mean Quality, its completeness indicator, or its correlation. Changing the manual KPI selection or the corner/guiding settings can change this composite.

Unavailable indicators are not treated as good measurements. An incomplete Below-mean Quality percentage is marked with an asterisk; its tooltip gives the assessed and enabled counts. A partial Score may still be displayed, but missing required data triggers REVIEW, and R1 and R2 are withheld when their required measurements are unavailable. A partial R3 remains available when the field measurement is valid; inspect its missing-data flags.

R3 is calculated when field measurements are available and at least one KPI qualifies. Enable Use R3: strongly correlated KPIs to use its score as the active Score. It selects indicators automatically for each group when their absolute Pearson correlation with PSF signal weight is at least 0.7, accepting both positive and negative relationships. It requires at least three paired subframes with varying measurements. The master is excluded; manually rejected subframes remain included. Strong correlation describes association, not the cause of poor quality, and can be unstable in small groups.

PSF signal weight is the correlation reference only. It is excluded from R3 selection and contributes no direct weight to R3; self-correlation is not used as selection evidence. Each qualifying indicator has weight 1; excluded indicators have weight 0. Manual weight values are retained, including any zeros, and restored when the option is disabled. Corner quality participates when Include corner measurements (R2) is enabled; guiding also requires logs and a guiding mode other than Ignore. The selected guiding mode still controls missing-data handling when guiding is included.

With Include corner measurements (R2) enabled, the FWHM and eccentricity of each of the four corners are also tested separately against PSF signal weight. Each of these eight indicators is included with weight 1 when its absolute correlation reaches 0.7 with at least three valid paired subframes. The Corner quality composite remains a separate candidate. A corner FWHM can qualify even if eccentricity or another corner is unavailable. Center FWHM contributes through the composite's corner-to-center ratios; it is not a separate scoring candidate.

Each selected corner indicator contributes its own penalty to R3. Larger FWHM and eccentricity are worse, regardless of the correlation's sign. Several qualifying corner indicators therefore give corner performance more combined influence. The Below-mean Quality composite retains its manual indicator selection; qualifying individual corner indicators do not redefine it. Disabling correlation scoring restores the manual weights and the single Corner quality contribution.

R3 assesses the same Below-mean Quality values shown in the Review table and correlation plot, and includes this composite only if its own correlation passes the threshold. Score itself is never a selection candidate. If no KPI qualifies, the script reports No strongly correlated KPIs and leaves the R3 score and rank unavailable. With Use R3 enabled, Score retains the manual evaluation, including its weights, review reasons, and ranking. The weight controls show those retained manual values. R4 omits the unavailable R3 rank. This behavior is determined separately for each filter group.

The qualifying R3 KPIs are listed in the bottom message area on every tab. Hover over that report or R3 for each correlation, sample count, and exclusion reason. Changing this option reuses existing measurements.

Clicking Measure corners afterwards measures missing regions and recalculates the selection for every group. When corner scoring is enabled, Corner quality and the eight individual corner indicators are included only when each meets the strong-correlation threshold. Turning corner scoring off excludes them and recalculates the selection using the field-only indicators. Clearing measurements also removes their scoring contributions until they are measured again.

The master receives comparable measurements and a score against the subframe baselines. It does not influence the baselines or consume a place in the REVIEW quota. Guiding measurements apply only to individual exposures, so the master has no guiding contribution.

8 R4: Rank of ranks

[hide]

R4 combines three views of image quality into one ranking. Each available ranking has equal influence after normalization. It averages the rank positions, rather than the underlying quality scores.

Table 4

Component

What it evaluates

R1

Field quality using your manual weights, without corner measurements.

R2

Field and corner quality using your manual weights.

R3

Quality using equally weighted indicators that strongly correlate with PSF signal weight.

For each component, normalized rank = (rank − 1) / (N − 1), where N is the number of images with a valid rank for that component in the group. The worst rank becomes 0 and the best becomes 1. If only one image has a rank, its normalized value is 0.5.

R4 Score = mean of the available normalized R1, R2, and R3 ranks.

The R4 column then ranks these combined scores: 1 is worst, and larger rank numbers are better. The combined Score itself ranges from 0 to 1, with higher values indicating better relative quality. Rank and Score are different values.

For example, suppose each component ranks 11 images and one image has R1 = 3, R2 = 7, and R3 = 9. Its normalized ranks are 0.2, 0.6, and 0.8. Its combined Score is (0.2 + 0.6 + 0.8) / 3 = 0.533. Its R4 position depends on the combined scores of the other images. If only R1 and R3 are available with those values, the combined Score is (0.2 + 0.8) / 2 = 0.500.

R2 is omitted when Include corner measurements (R2) is off or that image has no valid R2. Other unavailable ranks are also omitted; they never count as zero. An image with no available ranks has no R4. A partial result can still require REVIEW. Corner scoring also affects which indicators participate in R3, so switching it can change both R3 and R4.

To use this method, enable Use R4: rank of ranks in Score selection. The Score column, REVIEW shortlist, and best-subframe comparison then use the combined score. Use R3: strongly correlated KPIs selects the R3 score instead; the two options are alternatives. Leaving both off uses manual scoring. R1–R4 remain visible in every mode when their required measurements exist, and changing modes does not measure images again.

Select R4: rank of ranks in Sort by to order the table by R4, independently of the active Score mode. Hover over an R4 value to see the contributing ranks, their population sizes, normalized values, and any omissions. R4 includes the comparison master, uses all ranked images in the group regardless of the table filter, and resolves equal scores by filename.

Manual weights remain editable in rank-of-ranks mode because they determine R1 and R2. R3 uses its independently selected, equally weighted indicators. Below-mean Quality has the same definition in every scoring mode. The Main issue and Score tooltip identify the ranks that most reduce the combined score.

All eight manual Score components have columns: PSF weight, FWHM, Stars, Field eccentricity, Corner quality, Below-mean Quality, Guiding quality, and Sky background. In correlation mode, columns for qualifying individual corner FWHM and eccentricity indicators appear at the right of the table; scroll horizontally to view them. Their tooltips report correlation and sample count. Missing measurements remain marked as unavailable. The quality-column tooltips explain their meaning and current inclusion in Score.

Main issue identifies a scoring contribution, not a diagnosis. For example, elongated stars may be associated with guiding, wind, or optical effects; inspect the image to decide whether to reject it. Hover over the score, issue, or quality columns for contribution details and missing-data information.

R1, R2, R3 and R4 include the master in their comparison ranking. Their values remain group ranks when the table is filtered; they are not renumbered as visible row positions. Equal scores are resolved consistently by filename.

Use Sort by in the Sort and filter area. Score, field-width, corner-quality, sky-background, and Below-mean Quality sorts show the poorest values first; PSF signal weight and star count show the smallest values first. R1, R2, R3 and R4 show rank 1 first. The button beside the selector shows Ascending or Descending. Click it to toggle the direction. Choosing another criterion restores that criterion's default direction. The selected criterion and direction are saved in process instances. Below-mean Quality keeps complete comparisons first, with Score resolving percentage ties in the chosen direction; incomplete comparisons follow in both directions.

Acquisition time starts with the earliest full date and time. Toggle to Descending for latest first. In both directions, dated subframes come first, undated subframes follow, and the master is last. Filename sequence numbers do not participate in this ordering. Sorting preserves the selected image and manual rejection choices. The quality plots retain their own order.

Choose Guide minimum, Guide maximum, or Guide average to sort by the corresponding guiding column. These start with the largest error first; use the direction button to put the smallest error first. Values are sorted numerically in arcseconds, including partial measurements marked with an asterisk. Unavailable values follow measured values in both directions, and the master is last. The choice and direction are saved in process instances and also determine the sequence for Rotate subframes (Review order).

Enable REVIEW candidates only to show just flagged subframes. This filter also hides the master. It changes table visibility without marking files for rejection or limiting the quality plots to those rows.

Hover over a REVIEW marker to see why the image was selected. For the Review worst percentage, the tooltip gives its group position, the rounded-up shortlist size, Score, and largest score penalties. It also lists any missing or insufficient measurements and guiding-data issues that require inspection. Both reasons appear when both apply. The explanation follows the current scoring settings and stays consistent when the table is sorted or filtered. REVIEW leaves the rejection decision to you.

When corner measurements are enabled, the REVIEW tooltip also explains unavailable preview measurements individually. It reports the detected-star count and required minimum, a missing or invalid FWHM or eccentricity result, or the recorded processing error. A preview with no result is described as not measured. 16 Guiding measurements and quality

[hide]

The script matches PHD2 samples to each subframe's UTC exposure start and duration. Guide min, Guide max, and Guide avg report the combined RA/Dec displacement in arcseconds. The guider's recorded pixel scale converts its measurements to arcseconds; the imaging camera's pixel scale sets the quality thresholds.

Let p be the image pixel scale in arcseconds per pixel. The guiding quality value is:

G = (minimum + 2 * average + maximum) / 4

The average contributes 50 percent, and the minimum and maximum each contribute 25 percent. This balances typical performance with the observed extremes. For unequal X/Y image scales, the smaller available scale is used. The UI displays the Good, Medium, and Bad boundaries in arcseconds for your setup. For example, an image scale of approximately 0.507 arcseconds per pixel gives a Good limit of approximately 0.507 arcseconds and a Medium limit of approximately 0.887 arcseconds; larger errors are Bad.

Files that have changed, are missing, or have an occupied original path cannot be restored. Existing files are never overwritten. Already restored files are identified in the list. If restoration stops partway through, reopen the same move journal to restore the remaining eligible files. Each restoration also saves an SQR-undo journal in the rejection folder.

After moving, rerun WBPP from the remaining originals. Refresh its inputs and exclude the rejection directory. Use an output directory appropriate for the new run so that you can distinguish the new integration from the reviewed run.
