1 Description

[hide]

Star Spike Protection Mask 1.3 creates a 32-bit floating-point grayscale mask in PixInsight. It selects bright stellar cores, measures their diffraction spikes, protects their halos, and softens the mask boundaries. An optional final Gaussian blur smooths the whole mask.

Black protects. White allows processing. Leave Invert Mask OFF.

The script reads the source without changing its pixels. It is intended for stretched stars-only images with approximately perpendicular diffraction spikes. The runtime target is PixInsight 1.9.5 with V8; earlier versions have not been verified.

2 Parameters

[hide]

2.1 Minimum bright-core area (px)

Default: 100. This is the main lower cutoff. A core must contain at least this many connected pixels above the core intensity threshold after slight smoothing. Raise the value to protect fewer, larger or brighter stars. Lower it to include smaller stars. This is a brightness proxy based on size, not a calibrated stellar magnitude. It remains useful when stars have identical saturated peak intensities.

2.2 Core intensity threshold

Default: 0.60. The normalized sample value used to define the bright core. Changing it changes the measured area and therefore which stars qualify. Actual samples are measured; an STF display stretch has no effect.

2.3 Minimum peak intensity

Default: 0.80. A separate lower brightness cutoff on the maximum source sample within each detected core. For RGB data the brightest channel is used. Both the area and peak cutoffs must be met.

2.4 Require detected diffraction spikes

Default: enabled. Reject qualifying cores that do not have the requested number of detected spike arms. Disable to include other bright stars too. A star with no detected arms receives circular core/halo protection.

2.5 Minimum detected spike arms

Default: 2. Two accommodates clipped stars and crowded or asymmetric patterns. Three or four makes selection stricter but may exclude real stars near the frame boundaries.

2.6 Minimum spike contrast

Default: 0.025. Minimum intensity excess over adjacent side strips. Lower values admit fainter spikes and potentially more unrelated structure; higher values require stronger evidence. This value also influences halo/background separation.

2.7 Measure spike angle automatically

Default: enabled. Estimates a shared orientation from up to ten large candidates, then refines the angle for each star. Disable to use the manual angle.

2.8 Spike-axis angle (degrees)

Default: 0. Used only with automatic angle measurement disabled. The angle is measured clockwise from the horizontal in image coordinates. Either axis of the orthogonal pattern can be used; angles are equivalent modulo 90 degrees.

2.9 Maximum spike length (px)

Default: 600. Maximum measured distance from the star center before adding the tip margin. Increase if the console reports spikes reaching this limit.

2.10 Spike-tip margin (px)

Default: 20. Additional protection past each measured tip. Increase to protect faint extensions beyond the detected endpoint.

2.11 Edge softness (px)

Default: 6. Width of the smooth transition around the star disks. Spike sides and ends use proportional transitions. Zero creates hard boundaries before any optional whole-mask blur.

2.12 Halo intensity floor

Default: 0.05. Lower it to extend circular halo protection; raise it to tighten the mask around the core. Local background estimates also constrain halo extent.

2.13 Blur entire mask (Gaussian)

Default: disabled. Applies PixInsight's native parametric Convolution to the completed mask, after all stars and spikes have been combined. This is additional to edge softness. It does not change the selected star count.

2.14 Blur sigma (px)

Default: 2.0; range: 0.1 to 25. Gaussian standard deviation in original-image pixels. Larger values give stronger smoothing. Narrow black spikes can become gray and therefore receive less protection. Inspect the preview before applying strong blur.

2.15 Offer to save the result as XISF

Default: enabled. Opens PixInsight's save dialog after Create mask. The script prevents saving over the source image. Cancelling leaves the newly created mask open for inspection or later saving.

3 Usage

[hide]

Open and activate the stretched stars image. Run Script > TG Scripts > StarSpikeProtectionMask. Select the source in Settings, set the minimum bright-core area, and click Update preview.

In the Mask preview tab, inspect the result with the zoom toolbar, the mouse wheel, and drag panning. Use 1:1 to inspect narrow spikes. Enable Show source image for comparison to compare the same region against the source. Return to Settings to adjust the limits, then update the preview again.

Click Create mask to open the full-precision result and optionally save it as XISF. Cancelling the save dialog keeps the mask open. Select it as the mask for your original image, enable masking, and leave inversion off. No mask is applied automatically.

5 Symbol buttons and saved instances

[hide]

The bottom toolbar uses native PixInsight symbols matching TGScriptSkeleton. From left to right: New instance (triangle), Update preview (preview magnifier), Analyze/count stars (find symbol), then Create mask (green checkmark), Close (red cross), and Help (documentation icon). Hover over each symbol for its tooltip. Action names in this manual refer to these tooltips.

To preserve parameters, select the source, adjust the options and drag the triangle onto an empty workspace area. Double-click the resulting process icon to open PixInsight's Script instance panel, then click its blue Apply Global circle to reopen the mask dialog with the stored settings. Save process icons with PixInsight's Process > Process Icons > Save Process Icons command, or save the project, to retain them across sessions. Keep the script in its installed location.

The instance stores all selection, geometry, feathering and blur settings, the XISF save preference and the source view identifier. Source pixels and preview bitmaps are not embedded. A fresh menu invocation starts with defaults. If the saved source is closed or renamed, select it again in the dialog.

Dragging the instance onto a main image executes immediately on that image, overriding the stored source identifier. It creates a separate mask and leaves the target unchanged. This mode does not open a save dialog; the resulting mask remains open for File > Save As. Applying an instance to a preview is rejected to prevent a cropped mask from being mistaken for a full-image mask.

6 Preview behavior

[hide]

Update preview performs the same full-resolution detection, rasterization, feathering and optional blur used by Create mask. The viewer displays an 8-bit bitmap of that result; the saved mask retains 32-bit precision. Preview rendering creates no permanent image window and makes no change to the source.

Zoom controls provide fit-to-window, 1:1, magnification and reduction. Drag to pan. Source comparison changes the displayed bitmap while keeping the viewing scale. Source samples are displayed without an STF, consistent with the intensity measurements used for selection.

Changing a setting or selecting another image clears the old preview immediately. Click Update preview explicitly to recalculate; this is not a continuously updating real-time preview. Analyze/count stars calculates selection statistics without rendering a new preview. Create mask rereads the source and recomputes the result, so source edits made after a preview are included.

7 Algorithm

[hide]

The analysis begins with a full-image snapshot of the maximum nominal channel, clipped to the normalized range. Alpha channels are ignored. A separable three-tap smoothing kernel suppresses isolated pixels; eight-connected bright components provide core areas, intensity-weighted centers and peak values.

The largest candidates establish a shared spike orientation. Five-pixel ray samples are compared with flanking strips using a lower-quartile background estimate. Robust median profiles identify arms and measure their lengths, bridging short chromatic gaps. Stars clipped by the image boundary receive a center correction from the visible spike ridges. Opposite arms constrain overly short measurements. A radial median profile defines each halo.

Soft circular disks and four arms are combined using their pointwise maximum, then inverted to black-protects polarity. Optional Gaussian convolution is applied to the completed mask. There is no final histogram stretch or normalization. The output has the same width, height and orientation as the source.

8 Practical starting points

[hide]

On the supplied 6040 by 3956 stretched RGB test image, the default settings selected 371 stars. Of that selection, 130 had core areas of at least 200 pixels, 41 at least 400, and 11 at least 800. These are examples, not fixed targets: a different stretch, source revision or threshold changes the results. Use Analyze/count stars or Update preview to obtain the current selection.

For too many selected stars, raise the minimum area first. For a missing star, lower the area cutoff, then check the peak and spike criteria. For exposed spike tips, increase the tip margin or maximum length. For excessive circular protection, raise the halo floor. For a smoother transition everywhere, enable whole-mask blur and start at sigma 2.

9 Limitations and troubleshooting

[hide]

These defaults assume stretched stars-only data. Linear data needs much lower intensity thresholds, or a stretched copy used only to derive the mask. Nebulosity, merged cores, crowded fields, very faint spikes and non-orthogonal diffraction patterns can require manual review. Nearby small stars inside a protected halo or spike strip are also protected.

No stars selected means at least one cutoff is too restrictive for the actual sample values. An empty selection does not create an all-white mask. Use the Process Console Abort control to stop a long calculation; partial output windows are closed.

The mask is geometrically aligned with the source. Apply identical transformations to it if the target is later cropped, resized or rotated. A preview is for inspection only and must not be used as the full-precision output.
