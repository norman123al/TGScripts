1 Description

[hide]

ROI Linear Fit 1.1 uses PixInsight's native LinearFit on hidden source/reference and target ROI copies, recovers the applied affine transformation, and applies it to the entire target. Grayscale uses one fit; RGB uses separate fits per channel. The source stays unchanged. Temporary ROI images are closed after success, failure, and normal script abort. Existing user previews are preserved.

Requires PixInsight 1.9.5 with V8 and its native plotting objects. Images must be registered, have identical dimensions, and be both grayscale or both RGB. Matching dimensions alone do not establish alignment.

2 Parameters

[hide]

2.1 Source (reference)

The main image whose intensity scale is used as the reference. Source pixels are read-only. A missing or renamed saved source must be selected again; it is not silently replaced by the active image.

2.2 Target (to modify)

The main image receiving the full-image formula. It must differ from the source. A fresh launch selects the active image if available. Integer targets retain their precision; floating-point targets can optionally retain values outside the zero-to-one range. Normal alpha data is preserved. An attached mask is temporarily disabled to fit the whole target, then its enabled state is restored.

2.3 ROI coordinates and preview

X and Y are zero-based top-left coordinates; Width and Height are positive integer dimensions. The same rectangle is used in both images. X=100, Y=200, Width=300, Height=150 includes columns 100 through 399 and rows 200 through 349. A fresh launch starts with a 256 by 256 region, bounded by the active image.

Copy ROI from preview accepts an existing preview on the selected source or target. Only its rectangle is used; measurements always read the main image pixels. The saved instance stores explicit coordinates, so the original preview is not needed later. At least 32 pixels are required. Choose varying corresponding signal and avoid blank borders.

2.4 Reject low and Reject high

Defaults 0 and 0.92. Native LinearFit uses pixel pairs whose values are strictly inside the interval in both images. Limits must satisfy 0 <= low < high <= 1. These are normalized actual samples, independent of STF. All ROI data is available to native LinearFit subject to these limits; chart sampling does not reduce the fit data.

2.5 Clip final result to zero through one

Enabled by default, matching native LinearFit clipping. Disable only on floating-point targets to retain negative and above-white results. No rescaling is applied. The scatter line shows the untruncated formula regardless of this setting.

2.6 Show scatter plot after applying the fit

Enabled by default. Shows original target values against source values after successful application. The snapshot is captured before mutation. Disable this option before saving an instance intended for unattended execution. The preview magnifier always displays the plot without modifying either image.

2.7 Plot sample limit

Default 12000, range 100 to 100000, per channel. Small ROIs show all pairs. Larger ROIs use a repeatable stratified sample spanning the rectangle. This setting changes only the visualization, never the native fitting calculation. Rare outliers may be absent from the sample; increase the limit to inspect more data.

3 Usage

[hide]

Select Source (reference) and Target (to modify), enter the ROI or copy it from an existing preview, and click the magnifier to inspect a read-only fit and scatter plot. Close the chart, adjust settings if needed, then click the green checkmark to recalculate and apply the formula to the full target. Undo reverts the change. Save your image separately.

4 Installation and symbols

[hide]

Extract TG_Scripts_ROILinearFit_1.1.zip to a permanent location and keep its TG Scripts folder intact, including doc/ and rsc/. Register the folder with Script > Feature Scripts > Add. Run Script > TG Scripts > ROI Linear Fit. The identifier remains ROILinearFit. Remove an older duplicate registration if necessary. Execute Script File is also supported.

The bottom toolbar follows StarSpikeProtectionMask: triangle for New instance, magnifier for read-only Preview fit, green checkmark for Apply fit, red cross for Close, and documentation icon for Help. Hover for tooltips. The chart adds a Save symbol for PNG/SVG export. Closing a chart after applying does not undo the fit.

5 Understanding the scatter plot

[hide]

Horizontal axis: original target pixel value. Vertical axis: source/reference value at the corresponding position inside the ROI. Colored points lie inside both rejection limits; gray points fail at least one limit. Select Gray, R, G or B with the channel selector. The count states how many pairs are displayed out of the total ROI pixels.

The yellow straight line is source approximately equal to offset plus slope times original target. It uses the same full-ROI native LinearFit coefficients that are applied by PixelMath. It is not a new regression computed from the displayed sample. The chart title rounds coefficients for readability; execution uses full precision, also printed in the Process Console.

Noise and different spectral content produce scatter. A curved relation, multiple groups, or a broad cloud can suggest that one linear correction is insufficient for the chosen region. The plot is diagnostic, not proof of alignment or photometric accuracy. Values use actual samples rather than STF or separately processed preview pixels.

Preview and Apply each recalculate from current images; a cached preview fit is never reused. The chart retains its numerical snapshot, so applying the fit does not move the original points. If clipping is enabled, output below zero or above one is clipped during application, while the plotted line remains straight.

6 Exporting a plot

[hide]

Click the Save symbol in the chart and choose a PNG or SVG filename. Exports contain the displayed channel at 1200 by 760 pixels, or the corresponding vector canvas. Select and save each RGB channel separately if desired. Cancelling Save creates no file. Plots are not automatically saved and create no image windows.

7 Process instances

[hide]

Drag the triangle to the workspace to save source ID, target ID, X, Y, width, height, low and high rejection limits, clipping, post-apply chart preference, plot sample limit, and selected channel. The icon stores settings, not images, preview objects or fitted coefficients.

Double-click the instance and use the Script panel's blue Apply Global circle to restore the custom dialog. Save process icons or the project for later sessions. Keep the installed script at a stable path. Closed or renamed saved images leave selectors empty and require reselection.

Drop an instance onto a main image to execute directly. That image overrides the saved target only. The saved source and ROI remain in effect, and the fit is freshly calculated. A chart appears afterward if enabled; disable it for unattended execution. Preview targets are rejected. Direct execution reports missing source references instead of selecting another image.

8 Errors, cleanup and limitations

[hide]

Constant, heavily clipped or insufficiently varied regions can fail coefficient recovery. Each channel needs at least 32 usable unclipped, varying pixels. Choose a larger or more representative region. All channel transformations are verified before target modification.

Script-owned hidden ROI windows are closed in a cleanup block after success, error or normal abort. User previews and unrelated windows remain. If the fit applies successfully but chart display fails, the error explicitly says the fit was applied; Undo remains available. Closing the chart does not revert application.

The script does not align, stretch or automatically save images. Integer images are subject to their existing quantization. A single affine transformation may be inadequate for mismatched gradients or different spectral structures. This release is unsigned and should not be paired with an older detached signature.

9 Implementation and developer documentation

[hide]

The source includes function contracts and ownership comments. ROILinearFit_developer_notes.md documents the versioned parameter schema, native fit recovery, deterministic sampling and test coverage. Editable manual source is in documentation-source/.

Native LinearFit exposes no coefficient output property. The script measures the affine map from original target ROI values to the process result, excluding clipped endpoints, and verifies that map against all fitted ROI samples. It does not parse rounded console coefficients or replace native LinearFit with a reference-to-target least-squares calculation. PixelMath applies coefficients with 17 significant digits and a 64-bit working image.
