Provenance
The 226 otypedef records were retrieved on 2026-11-14 from:
https://simbad.cfa.harvard.edu/simbad/sim-tap/
ADQL query: SELECT * FROM otypedef
The script retains otype, label, description and path, sorted by otype.
These four values are unchanged. The separate presentation-label map provides
shorter or consistently capitalized names for some types. The JSON copy includes
both the extracted records and these presentation labels. It is supplied in an
open, machine-readable form for reuse; the script does not load it at runtime.
The snapshot is bundled, not downloaded at startup. Live object lookups also
use SIMBAD; their service terms are given at the source above.
